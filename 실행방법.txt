블록체인 거래 기록과 생성형 AI를 활용한 토큰화 펀드 배당 검증 자동화 — 실행 방법
A70021 김태진

====================================================================
0. 가장 빠른 확인 (설치 없음)
====================================================================
- 배포된 대시보드: https://sto-dividend-dashboard-oy5krt4u3fyya5btd2fjtz.streamlit.app/
- 인터넷 브라우저로 열면 바로 보입니다. 마지막 'AI 감사 관제실' 탭은 GPU PC가 켜져 있을 때만 화면이 나옵니다 (6절)

====================================================================
1. 준비 (Windows 기준, 약 3분)
====================================================================
- Python 3.12 (python.org). 설치할 때 "Add python.exe to PATH" 선택
- 압축은 짧은 경로에 풉니다 (예: 바탕화면, 다운로드, C:\sto). 폴더가 너무 깊으면 Windows 경로 길이 제한(260자)에 걸려 패키지 설치가 실패할 수 있습니다
- 압축을 푼 폴더(main.py가 있는 폴더)에서 명령 프롬프트를 열고:

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt

====================================================================
2. 한 번에 실행 — API 키·GPU 없이 (채점용 기본 경로, 약 10초)
====================================================================
    python main.py --no-collect --no-llm

- 저장된 블록체인 데이터와 저장된 AI 결과로 전처리 → 분석 → 문서 대조 → Excel 점검표까지 다시 만듭니다
- 화면 끝에 단계별 소요 시간, 잔고 대사 오차, AI 판정 요약이 나옵니다
- 결과 파일
    reports\dividend_check.xlsx   Excel 점검표 (실행 요약, AI 판정, AI 추출 조건, 사람 대조표)
    reports\benji_report.md       AI 점검 리포트
    검증\data\clean\              전처리·분석 결과 (CSV, 차트 PNG)
- 참고: 옵션 없이 python main.py 만 실행해도, API 키가 없으면 수집을, Ollama가 없으면 AI 단계를 알아서 건너뜁니다

====================================================================
3. 대시보드 (로컬)
====================================================================
    python -m streamlit run dashboard/app.py

- 브라우저에서 http://localhost:8501 이 열립니다. 또는 2절 명령에 --dashboard 를 붙이면 실행 후 바로 뜹니다
- 탭: 배당 지급률 / 자금 흐름 / 지급 요일 / 문서 대 온체인 / AI 점검 리포트 / 이상 탐지 / 원천 데이터 / AI 감사 관제실

====================================================================
4. (선택) 블록체인 데이터 새로 수집 — API 키 필요
====================================================================
- .env.example 을 .env 로 복사하고 값을 채웁니다
    ETHERSCAN_API_KEY=   (etherscan.io 무료 키. 거래 기록 수집용)
    SEC_USER_AGENT=      (이름과 이메일. 투자설명서를 다시 받을 때만 필요: python 검증\09_collect_prospectus.py)
- 실행: python main.py --no-llm   (수집 약 1분)

====================================================================
5. (선택) 생성형 AI 단계까지 실행 — GPU와 Ollama 필요
====================================================================
- Ollama 설치 (ollama.com) 후: ollama pull phi4:14b   (약 9GB)
- 실행: python main.py   (GPU 기준 AI 단계 약 50초. GPU 없이 CPU만으로는 약 20분)
- LLM은 투자설명서에서 배당 조건을 문장 번호와 함께 뽑고 리포트 문장을 씁니다. 판정은 코드가 합니다

====================================================================
6. (선택) AI 감사 관제실 — 멀티 에이전트 시연 (GPU PC 전용)
====================================================================
- 에이전트 여섯(총괄·문서 분석·조사·검증·감사·보고)과 담당자(사람)가 조사하고 결재하는 화면입니다
- 필요: GPU, Ollama 모델 gemma4:26b-a4b-it-qat, Docker Desktop(Langfuse), Node.js
- 순서 (agent 폴더 안의 안내와 같음)
    1) agent\langfuse\.env.example → .env 채운 뒤:  cd agent\langfuse  →  docker compose up -d
    2) agent\.env.example → .env (Langfuse 키):     pip install -r agent\requirements.txt
    3) cd agent\console  →  npm install  →  npm run build
    4) cd agent  →  uvicorn console_api:api --port 8700   →  http://localhost:8700
- 3절 대시보드의 'AI 감사 관제실' 탭에 같은 화면이 들어옵니다

====================================================================
7. 문제가 생기면
====================================================================
- 'python'을 찾을 수 없음: Python 설치 때 PATH 추가를 빠뜨린 경우. py -3.12 로 바꿔 실행
- pip install 중 "No such file or directory" 오류: 경로가 너무 긴 경우. 폴더를 C:\sto 처럼 짧은 곳으로 옮겨 1절부터 다시
- 대시보드 포트 충돌: python -m streamlit run dashboard/app.py --server.port 8502
- 한글이 깨져 보임: 명령 프롬프트에서 chcp 65001 실행 후 다시 실행
